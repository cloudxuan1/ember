## 0. 阶段 0 的边界(先说清做什么、不做什么)

**做**:能装到主屏幕的三栏壳、进门口令、设置页最小可用、部署上线手机实测。
**不做**:任何聊天功能(阶段 1)、任何真的小手机功能(阶段 3)、深度视觉打磨(mockup 轮)。
原则:**不做假功能**——没开通的东西明确标"施工中",绝不放一个点了没反应的按钮装样子。

## 1. App 身份

- **安装方式**:iPhone Safari 打开网址 → 分享按钮 → "添加到主屏幕"。设置页里放一条图文引导(第一次装完就用不到了,但客人来了能照着装😼)。
- **装完的效果**:主屏幕有独立图标,点开全屏无浏览器地址栏,和真 app 无异;竖屏使用。
- **图标与名字**:🔴待拍板。名字显示在图标下方,建议短(2-4 字)。候选:`ember` / 轩起一个。图标阶段 0 用简洁占位(纸底+单字或小火苗),以后可换 fable酱形象。
- **状态栏**:顶部时间电量那条,底色与 app 纸色融合,不出现突兀黑条。

## 2. 进门流程

1. 首次打开 → **口令页**:一个输入框 + 一个"进门"按钮,别的什么都没有。输对进门,**30 天内不再问**(和审核台同一套机制、同一个口令,不用记两个)。
2. 输错:输入框抖一下 + 红字"口令不对",不跳页不弹窗。
3. 进门后落在**聊天栏**。🔴待拍板二选一:
   - **A(我推荐)**:每次打开固定落聊天栏——行为可预期,聊天也是绝对主场
   - B:记住上次停留的栏,下次从那开始
4. 退出登录只在设置页里有(防误触),点了回口令页。

## 3. 底部三栏导航(全 app 的骨架)

- **布局**:通栏贴底,高度约 56px + iPhone 底部横条安全区(不会被小白条压住)。你嫌参考图那种底栏占地方——咱做**细**:小图标 + 小字,不做大黑药丸。
- **三栏与顺序**(你定的):左**聊天** · 中**小手机** · 右**设置**。
  - 🔴栏名待拍板:"小手机"这栏对外叫什么?候选:百宝箱 / 小手机 / 玩具箱 / 轩起名。"设置"就叫设置,别整花活。
- **当前栏**:图标+字实心炭黑;非当前栏灰色。点击**瞬时切换**,不做滑动动画(快、稳、省电)。
- **切栏保状态**:从聊天切到设置再切回来,聊天栏停在原处(滚动位置、输入到一半的字都在)——阶段 0 就把这个骨架做对,后面所有功能白赚。
- **不做手势左右滑切栏**:和以后聊天里的滑动手势(比如侧滑看会话列表)会打架,底部点按足够。

## 4. 三栏在阶段 0 各长什么样

### 4a. 聊天栏(占位态)
- 空状态页:居中一个小火苗图形 + 一句话文案("聊天施工中,阶段 1 见 🔨"之类,文案我来写得可爱点)+ 无任何可点元素。
- 不放假输入框、假气泡——看起来像坏了的功能比没有功能更糟。

### 4b. 小手机栏(占位态)
- **卡片网格**:两列卡片流(参考你给的黑白卡片图的清爽劲儿),阶段 0 放两张**灰态占位卡**:"日记"和"纪念日历",卡上有小图标 + 名字 + 一行小字"未开通"。
- 点灰态卡:卡片轻轻晃一下 + 顶部飘一条小提示"阶段 3 开通"——有反馈,但明确没功能。
- 这样你阶段 0 就能在真手机上感受卡片的大小、间距、一屏几张,给阶段 3 的日记卡定调。

### 4c. 设置栏(阶段 0 唯一真能用的栏)
分组列表,从上到下:
1. **审核台**:一行"打开审核台 ↗"——点了在 app 内弹出一层浏览器浮层(iOS 自带,右上角"完成"一点就回到 app,不会迷路跳丢)。旧审核台原样不动。
2. **账号**:退出登录(点了要二次确认"真退?",防误触)。
3. **添加到主屏幕教程**:图文三步(给还没装的时候看)。
4. **关于**:版本号一行(比如 `阶段0 · 2026-07-25`)——你报障时念这个,我立刻知道你跑的是哪版。
5. **预留分组**(灰字标"后续开通"):聊天参数(模型/thinking/联网默认开关,阶段 1)、外观(阶段 4+)。

## 5. 部署与共存

- 新前端住 `ember.cloudxuan1.com/` 根路径;审核台仍在 `/review`,互不打扰;后端接口路径全部不变。
- 上线动作:进 ember 现有 docker 编排加静态目录挂载,一次部署,以后改前端只是换静态文件,秒级生效。

## 6. 手机适配硬指标(验收要逐条过)

- 刘海/灵动岛、底部小白条:内容永不被遮挡(安全区适配)。
- 所有可点目标 ≥ 44px(苹果人机指南的下限,手指不误触)。
- 竖屏为主;横屏不崩(能看,不专门优化)。
- 只做浅色纸感,**暂不做深色模式**。🔴待拍板:你夜里刷手机多吗?多的话深色提上阶段 4 日程。
- 字号跟随系统的"更大字体"设置不炸版(基础档即可)。
