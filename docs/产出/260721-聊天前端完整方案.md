## 二、抄袭地图(每一处抄哪家,查证过的)

### 1. chat-lite(轩自己的仓库,随便搬)
- **thinking 折叠面板**:轩点名喜欢的展开样式,原样移植
- **缓存命中徽章**:回复气泡下 ⚡ + 橙色等宽数字 `命中/总输入`,原样移植(index.html `addCacheBadge`)
- 联网搜索来源折叠(默认一行"来源 N 条",点开展开)、密码门禁思路、SSE 流式渲染——全是现成验证过的
- ⚠️ chat-lite 的 Worker 缓存打法是 OpenRouter 版滚动双断点,ember 后端接 Anthropic 直连时改用星露谷验证过的三断点(见提示词缓存剧本)

### 2. homunculus(github.com/yerph/homunculus,MIT ✅)
- 定位:**CC/API 双模切换的完整样板**——API 模式直调,CC 模式经 MCP 把消息塞进 Claude Code 上下文,还有跨模式上下文同步(cc-sync)
- 本期只抄它的**架构形状**:前端只对 ember 后端一个统一聊天接口说话,"大脑是谁"是后端的一个可换参数 → 二期接 CC 时前端一行不用改
- 二期真做 CC 接入时,它的 chat-server 路由层就是抄袭对象(Node/Express,MIT 随便抄)

### 3. anno-mcp(github.com/Shitsuten/anno-mcp,⚠️ 未标许可证)
- 共读的交互设计非常合胃口:上传 PDF/EPUB/TXT → 翻页阅读器 → **人和 AI 各自划线批注、两种颜色并存**,像真的在同一本书上留笔迹;还有夜间模式/生词本/全文搜索
- ⚠️ 没写许可证 = 法律上默认版权保留,**代码不能直接抄**,只能抄交互思路自己实现
- 它是 MCP 服务器形态(Node+Python 提文本),搬进网页要把 MCP 工具改成 REST 接口——工作量不小,这也是共读排后的原因之一

### 4. Aion(轩用过的)
- 群聊规则:一人一轮 + @点名单独答。只抄规则,不抄它给第二 AI 建记忆系统那套

### 5. 星露谷游戏桥(自家的)
- 提示词缓存三断点(已验证)、SSE 流式、打字机/IME 处理经验

### 6. 视觉参考(轩投喂,2026-07-21)
- **Daygram 六张截图**:米白纸感底色、衬线数字、红点强调、点阵时间轴、月份/年份圆钮切换、写作页斜纹边框——日记功能照着做,重点参考轩点名的三张(列表视图/写作页/年份视图)
- **黑白卡片 app 一张**:中栏"小手机"的卡片阵列质感(清爽、黑白卡片混排、点进去是子功能);轩明说:底色喜欢、底部导航嫌占地方要改轻、其他配色要重调

## 三、架构(定稿)

```
手机浏览器(PWA,添加到主屏幕)
   │  frontend/ 静态文件,零构建 vanilla HTML/CSS/JS
   │  底部三栏:聊天 | 小手机 | 设置
   ▼
ember 后端(VPS docker,现有 FastAPI)
   │  新增聊天网关:统一 /chat 接口(SSE 流式)
   │  ├─ 大脑适配层:现在=Anthropic/OpenRouter API,二期=CC(homunculus 路子)
   │  ├─ 提示词缓存:三断点打法(剧本)
   │  ├─ 上下文压缩:阈值触发滚动摘要(详见下)
   │  └─ 记忆库就在同一后端——聊天记忆直连,不用出门
   ▼
Anthropic API(Claude)+ OpenRouter(GPT 等群聊外援,一把 key 搞定多模型)
```

**上下文压缩(接 API 的保命功能)**:对话超过阈值(比如 8 万 token)时,把最老的消息压成一段摘要,保留最近 N 轮原文。⚠️ 和缓存有天然冲突——压缩会改写前缀导致缓存全灭,所以**只在阈值触发时压一次、接受那一轮的缓存 miss**,不做每轮小修小补(剧本里 kiwi 的坑就是动态内容毁前缀)。具体参数施工时调。

**图片**:前端选图 → 传 ember 后端存盘 → 走 API 的视觉能力发给模型。

## 四、分阶段施工计划(每阶段一个会话,测试当闸门)

### 阶段 0:骨架(半天量级)
`frontend/` 目录 + 底部三栏壳 + PWA manifest(主屏图标/全屏)+ 设置页最小版(旧审核台跳转链接)+ VPS 部署打通手机实测。
**验收**:轩手机添加到主屏幕,点开像 app,三栏能切,设置里能跳旧审核台。

### 阶段 1:单聊(主菜,欧洲行的刚需)
统一 /chat 网关(API 大脑)+ SSE 流式 + thinking 开关/折叠面板 + 联网搜索 + 发图片 + 缓存三断点/命中徽章 + 上下文压缩 + 会话列表(历史存后端,不再 localStorage)。
**验收**:手机上和 fable酱完整聊一场:开 thinking、发图、看到 ⚡ 缓存命中、长对话不爆。

### 阶段 2:群聊
GPT 经 OpenRouter 进场;一人一轮 + @点名规则;群聊时间线 UI(谁说话头像区分)。
**验收**:轩、fable酱、GPT 三方一场群聊,规则跑对。

### 阶段 3:中栏首发——日记 + 纪念日历
日记 = Daygram 风(米白/衬线/红点/点阵),但**解除 Daygram 的"一天一格"限制**——一天想写几条写几条、不限长度(轩 2026-07-21 点名的痛点:天天当备忘录用,30 格不够);fable酱代写日记走聊天里一句话触发;纪念日历吃记忆库现成数据。
**验收**:Daygram 三张参考图对照,轩点头。

### 阶段 4+(欧洲行后,不占行前工期)
共读(anno 交互自己重写)、音乐/健康/其他小手机功能、CC 大脑接入(homunculus 路子,连带 mac mini 议题)、UI 深度美化。

**行前底线(约 2026-07-30 前)**:阶段 0+1 必须完成,阶段 2、3 尽力,阶段 4 不碰。
