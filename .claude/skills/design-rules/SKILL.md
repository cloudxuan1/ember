# 界面规矩

这些是我的口味，不是死规定。这里只写不要什么，用什么办法做到看情况挑；拿不准就出预览给我挑。

## 不要

1. 点开东西在原地往下展开，把下面的内容挤走；展开以后里面再塞一堆按钮，更烦。
2. 点开以后一下铺得很长，要翻回上面才能关掉。
3. 打字的时候输入框被键盘挡住，或者一点进去页面就乱跳。（iPhone 弹键盘时网页不会变矮，贴在底部的框会被盖住。）
4. 两个字的短选项一个占一行，越排越长。
5. 短选项挤成一大坨自动换行。我喜欢一排横着滑、后面的藏起来。
6. 所有操作全收进「···」。

## 踩过的坑（直接照做，别再绕；全过程在 in-phase 的 CLAUDE.md「已解决问题」）

1. **iPhone 点输入框自动放大**：viewport 那行加 `user-scalable=no`。输入框的字小于 16px 也没事，iPhone 上手动捏合照样能缩放。
   ❌ 弯路：给输入框改成 16px。
2. **iPhone 上虚线忽长忽短**：虚线一律用 `border: dashed` 画。
   ❌ 弯路：`repeating-linear-gradient`、伪元素、`background-size` 裁剪。iOS 会把渐变按元素大小拉伸。
3. **内容把列撑宽，iPhone 整页被缩放**：flex / grid 里的列加 `min-width: 0`。
   ❌ 弯路：挨个改输入框的 `min-width`、`contain: inline-size`、全局 `overflow: hidden`。
4. **面板里改了、界面也跟着变了，关掉却没存**：所有关法（点叉、点背景、往下滑）都要存，或者一改就自动存。

## 验收

- 在我的 iPhone 上点进输入框，连着打三行字：一直看得见在写什么，页面不跳。
- 点开再关掉，原来看到的位置不变。
